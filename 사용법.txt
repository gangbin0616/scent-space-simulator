Scent Space Simulator 사용법
============================

가장 쉬운 실행 방법
-------------------
1. 받은 zip 파일을 먼저 압축 해제합니다.
2. 폴더 안의 "1_실행하기.html" 파일을 더블클릭합니다.
3. 브라우저가 열리면 상단 메뉴에서 "시뮬레이터" 또는 "3D 워크스루"를 누릅니다.

중요:
- "1_실행하기.html"은 서버 없이 바로 실행되는 단일 파일입니다.
- 인터넷이 없어도 동작하도록 필요한 코드가 안에 들어 있습니다.
- "index.html"은 직접 더블클릭하지 마세요. 개발용 파일이라 브라우저 보안 정책 때문에 안 열릴 수 있습니다.


Mac에서 예비 실행 방법
----------------------
"1_실행하기.html"이 안 열리거나 화면이 비어 보이면 아래 방법을 사용하세요.

1. "2_Mac_서버로_실행.command"를 더블클릭합니다.
2. 브라우저가 자동으로 열립니다.
3. 주소는 보통 아래와 같습니다.
   http://127.0.0.1:4173/

서버 방식으로 실행 중일 때는 브라우저 주소가 127.0.0.1로 시작합니다.


끄는 법
-------
실행 방법에 따라 다릅니다.

1. "1_실행하기.html"로 실행한 경우
   - 브라우저 창만 닫으면 됩니다.

2. "2_Mac_서버로_실행.command"로 실행한 경우
   - "3_Mac_서버_끄기.command"를 더블클릭합니다.
   - 그 다음 브라우저 창을 닫으면 됩니다.


다시 키는 법
------------
1. 가장 쉬운 방법
   - "1_실행하기.html"을 다시 더블클릭합니다.

2. 서버 방식으로 다시 켜기
   - "4_Mac_서버_다시실행.command"를 더블클릭합니다.


자주 나는 오류와 해결법
-----------------------
문제: "사이트에 연결할 수 없음", "127.0.0.1에서 연결을 거부했습니다"
해결:
- 서버 방식으로 켜지지 않은 상태입니다.
- "2_Mac_서버로_실행.command"를 다시 더블클릭하세요.
- 그래도 안 되면 "4_Mac_서버_다시실행.command"를 더블클릭하세요.

문제: "1_실행하기.html"을 열었는데 화면이 하얗게 비어 있습니다.
해결:
- 브라우저를 새로고침합니다.
- Safari에서 안 되면 Chrome으로 열어보세요.
- 그래도 안 되면 "2_Mac_서버로_실행.command"로 실행하세요.

문제: Mac에서 command 파일을 열 수 없다고 나옵니다.
해결:
- 파일을 오른쪽 클릭 또는 Control 키를 누른 채 클릭한 뒤 "열기"를 선택하세요.
- 그래도 안 되면 "1_실행하기.html"을 사용하세요.

문제: "Python 3을 찾을 수 없습니다"라고 나옵니다.
해결:
- 서버 방식에만 필요한 문제입니다.
- "1_실행하기.html"은 Python 없이 열 수 있으니 그 파일을 사용하세요.
- 꼭 서버 방식이 필요하면 https://www.python.org/downloads/ 에서 Python 3을 설치하세요.

문제: 3D 워크스루가 움직이지 않습니다.
해결:
- 3D 화면을 한 번 클릭한 뒤 W, A, S, D 키로 이동하세요.
- 마우스로 화면을 드래그하면 시선이 돌아갑니다.
- 키보드가 한글 입력 상태여도 보통 동작하지만, 안 되면 영어 입력 상태로 바꿔보세요.

문제: 파일을 다른 곳으로 옮겼더니 안 됩니다.
해결:
- 가장 안전한 방법은 zip을 다시 압축 해제한 뒤 폴더 전체를 그대로 두는 것입니다.
- "1_실행하기.html"만 따로 복사해도 보통 실행되지만, 문제가 생기면 폴더 전체를 같이 전달하세요.


발표/제출 전에 확인할 것
-----------------------
1. "1_실행하기.html"을 더블클릭해서 홈 화면이 뜨는지 확인합니다.
2. 상단 "시뮬레이터"를 눌러 2D 도면이 보이는지 확인합니다.
3. 상단 "3D 워크스루"를 눌러 3D 매장 화면이 보이는지 확인합니다.
4. 문제가 있으면 "2_Mac_서버로_실행.command" 방식으로 실행합니다.


파일별 역할
----------
- 1_실행하기.html: 가장 쉬운 실행 파일입니다. 먼저 이걸 쓰세요.
- 2_Mac_서버로_실행.command: Mac에서 로컬 서버로 여는 예비 실행 파일입니다.
- 3_Mac_서버_끄기.command: 서버 방식으로 켠 경우 끄는 파일입니다.
- 4_Mac_서버_다시실행.command: 서버가 꼬였을 때 껐다가 다시 켜는 파일입니다.
- 사용법.txt: 지금 보고 있는 안내문입니다.
