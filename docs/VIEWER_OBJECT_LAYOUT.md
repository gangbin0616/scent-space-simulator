# 3D Viewer Object Layout

3D 뷰어 오브젝트 배치는 `src/viewer-layout.js`가 기준입니다. 직접 숫자를 고쳐도 되지만, 좌표를 잡을 때는 별도 배치 툴을 쓰는 편이 안전합니다.

## 배치 툴

로컬 서버가 켜져 있을 때 아래 주소로 엽니다.

```text
http://127.0.0.1:4173/tools/layout-editor.html
```

배치 툴은 사이트 본 화면과 분리되어 있습니다. 3D 렌더링을 돌리지 않고 2D 도면 위에서만 좌표를 잡기 때문에 사이트가 덜 무거워집니다.

## 사용 흐름

1. 도면에서 기존 오브젝트를 클릭합니다.
2. 드래그해서 원하는 위치로 옮깁니다.
3. 오른쪽 입력창에서 `X`, `Y`, `방향 deg`, `크기`를 세밀하게 조정합니다.
4. `종류`와 `추가 개수`를 정한 뒤 `추가`를 누르면 같은 종류의 오브젝트를 여러 개 만들 수 있습니다.
5. 배치가 끝나면 `viewer-layout.js 복사`를 누릅니다.
6. 복사된 내용을 `src/viewer-layout.js`에 반영합니다.

## 좌표계

- `PLAN_WIDTH = 744`
- `PLAN_HEIGHT = 960`
- `x`: 왼쪽에서 오른쪽으로 증가합니다.
- `y`: 위에서 아래로 증가합니다.
- `angle`: 3D 오브젝트가 바라보는 방향입니다. 사이트 파일에는 라디안 값으로 저장됩니다.
- `scale`: 오브젝트 크기 배율입니다. 기본값은 `1`입니다.

## 필드

```js
{ key: "wall-shelf-a", x: 318, y: 620, label: "선반", kind: "shelf", angle: 1.571, anchor: 0.52, scale: 1, info: false }
```

- `key`: 오브젝트 고유 이름입니다. 중복되면 안 됩니다.
- `x`, `y`: 도면 좌표입니다.
- `label`: 표시용 이름입니다.
- `kind`: 3D 오브젝트 종류입니다.
- `angle`: 회전값입니다. 라디안 기준입니다.
- `anchor`: 기존 보조 배치값입니다. 보통 그대로 둡니다.
- `scale`: 크기 배율입니다.
- `info`: `true`면 3D 뷰어에서 클릭 설명이 뜹니다.

## 설명 표시 대상

현재 설명이 필요한 오브젝트는 아래 종류만 `info: true`로 둡니다.

- `glass-door`
- `exit-door`
- `window`
- `partition`
- `fan`
- `cooler`
- `thermometer`

향수 선반, 테이블, 식물, 니치 같은 장식 오브젝트는 보통 `info: false`로 둡니다.
