# 프로젝트 설명

## 개요

Scent Space Simulator는 향수 팝업 스토어의 공간 설계와 향 확산을 실험하기 위한 웹 기반 시뮬레이션 앱입니다.

사용자는 도면 위에 향 출발점, 도착점, 가벽, 서큘레이터, 온열 장치, 냉각 장치를 배치하고 각 향이 공간 안에서 어떻게 퍼지고 도착점에 얼마나 도달하는지 확인할 수 있습니다.

## 목적

향수 팝업 공간은 단순히 예쁜 동선만으로 설계하기 어렵습니다. 향은 벽, 바람, 온도, 체류 위치에 영향을 받습니다. 이 프로젝트는 공간 설계자가 아래 질문을 빠르게 실험할 수 있도록 만듭니다.

- 어떤 지점에서 향을 발향해야 하는가
- 체험존에 특정 향이 충분히 도착하는가
- 여러 향이 섞일 때 도착점별 비율은 어떤가
- 가벽이 향의 흐름을 막는가
- 서큘레이터 방향이 향을 원하는 곳으로 보내는가
- 온열/냉각 구역이 확산과 잔향에 어떤 영향을 주는가

## 현재 구현 방식

이 앱은 별도 빌드 과정 없이 실행되는 정적 웹 앱입니다.

- HTML: `index.html`
- 스타일: `src/styles.css`
- 앱 상태 및 Canvas 렌더링: `src/app.js`
- 도면 데이터: `src/floorplan.js`
- 향 확산 엔진: `src/simulation.js`

`src/floorplan.js`는 도면의 단일 기준입니다. 시뮬레이터와 2.5D 뷰어는 모두 같은 좌표, 같은 벽 데이터, 같은 walkable 판정을 사용합니다.

## 주요 화면

### 메인

프로젝트의 목적과 도면 미리보기를 보여줍니다.

### 360도 뷰어

도면 벽 라인을 기반으로 2.5D 공간감을 렌더링합니다. 실제 360도 사진은 아니지만, 도면과 연결된 빠른 공간 preview 역할을 합니다.

### 시뮬레이터

작업 앱 형태의 화면입니다. 왼쪽 패널에서 설정하고 오른쪽 큰 도면 맵에서 배치합니다.

## 현재 상태

현재 버전은 MVP와 실험 도구 사이의 상태입니다. 도면 기반 향 확산과 다중 향 비교는 작동하지만, 실제 유체역학 시뮬레이션은 아닙니다. 제품적으로는 빠른 공간 배치 실험과 데모에 적합합니다.

## 다음 방향

단기적으로는 UX와 시뮬레이션 조작성을 개선하는 것이 우선입니다. 장기적으로는 실제 panorama 이미지, 저장/불러오기, 리포트 출력, 배포 환경을 추가할 수 있습니다.
