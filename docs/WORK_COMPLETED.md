# 지금까지 한 작업

## 초기 구조

- 정적 웹 앱 구조를 구성했습니다.
- `index.html`, `src/app.js`, `src/styles.css`, `src/floorplan.js`, `src/simulation.js`를 중심 파일로 정리했습니다.
- Python 내장 서버로 바로 실행 가능한 형태를 유지했습니다.

## 도면

- `FLOORPLAN_SPEC.md` 기준 좌표계를 `src/floorplan.js`에 반영했습니다.
- 고정 벽, 곡선 벽, 하단 블록, 동적 가벽을 하나의 walkable mask 판단에 연결했습니다.
- `getWallLines()`를 통해 2.5D 뷰어와 시뮬레이터가 같은 벽 데이터를 사용하게 했습니다.

## 2.5D / 360도 스타일 뷰어

- 도면 벽 라인을 raycast로 읽어 화면에 벽면을 렌더링합니다.
- 드래그로 시야를 회전할 수 있습니다.
- 미니맵에 현재 위치와 시야 방향을 표시합니다.
- 벽면 세로 그라데이션, 선반 라인, 향수병 실루엣, 바닥 그림자, 클릭 마커를 추가했습니다.

## 향 확산 시뮬레이터

- 단일 향 field에서 source별 field/buffer 구조로 변경했습니다.
- 출발점은 최대 10개까지 추가할 수 있습니다.
- 도착점은 최대 10개까지 추가할 수 있습니다.
- 출발점마다 향 이름, 색상, 발향량, 퍼짐, 감쇠를 조절할 수 있습니다.
- 도착점마다 전체 농도와 향별 농도 막대를 표시합니다.

## 장치 효과

- 가벽은 동적 벽으로 확산을 차단합니다.
- 서큘레이터는 뒤쪽 흡입과 앞쪽 토출을 모두 계산하고 시각화합니다.
- 온열 장치는 주변 확산과 감쇠를 높이고 상승 파동으로 표시합니다.
- 냉각 장치는 주변 확산과 감쇠를 낮추고 느린 링으로 표시합니다.

## UX 정리

- 시뮬레이터 화면을 문서형 페이지에서 작업대형 앱 레이아웃으로 변경했습니다.
- 데스크톱 기준 왼쪽은 설정 패널, 오른쪽은 큰 설계도 맵으로 구성했습니다.
- 왼쪽 패널과 출발점/도착점 목록은 내부 스크롤을 사용해 화면 높이를 덜 차지하게 했습니다.

## 검증

실행한 주요 검증:

```powershell
node --check src\floorplan.js
node --check src\simulation.js
node --check src\app.js
```

Node smoke test로 확인한 항목:

- 고정 벽 차단
- 곡선 벽 차단
- 동적 가벽 차단
- 주요 walkable 영역 통과 가능
- `getWallLines()` 뷰어용 벽 라인 제공
- 향이 벽을 통과하지 않고 도착점까지 확산되는지 확인

브라우저 검증:

- `#home`, `#viewer`, `#simulator` 로딩
- 뷰어 드래그 후 캔버스 변화
- 시뮬레이터 출발점 10개, 도착점 10개 제한
- 향별 농도 막대 표시
- 런타임 예외 없음
